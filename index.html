Records

HeeHee plays the files in mp3/ and audio/, and only ever suggests songs it can actually play. Drop a new file in, reload, and it is picked up automatically. An .lrc with the same name replaces the generated captions with real timed lyrics.

Mood analysis

The local analyzer always runs. With this on, the two readings are blended, which helps with sarcasm and unusual phrasing. Nothing is sent unless you enable it and add a key.
